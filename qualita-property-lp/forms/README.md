静的確認版の `income-collection.js` には送信阻止処理があります。WordPressではCF7専用に物件・価格帯の引き継ぎ処理を接続し、送信阻止処理と確認版fieldsetを流用しないでください。

実物件の閲覧は本番の認証・権限を通します。GitHubへ実物件や個人情報を公開しません。
