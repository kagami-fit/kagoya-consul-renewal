# QUALITA紹介ページの比較・固定保存

## 一言で言うと

編集前と編集後を固定URLで残し、当時の写真・文言・見た目を比較できるフォルダーです。

## 何ができるのか

- 2026年10月10日の修正前・修正後を閲覧する。
- 現在の最新版と過去版を行き来する。
- 今後の修正時にも新しい保存版を追加する。

## 構成

- `index.html`：比較一覧。
- `registry.json`：保存した版の一覧と元コミット。
- `20261010-before/`：収益不動産への絞り込み前。
- `20261010-after/`：収益不動産へ変更した後。
- 各版の `snapshot.json`：写真・CSS・JS・HTMLの照合値。

## 使い方

GitHub Pagesの `/qualita-property-lp/versions/index.html` を開きます。保存の追加・検証は一つ上の `ABOUT.md` を参照してください。

## 状態

- 比較一覧：更新可能。
- 日付付きフォルダー：固定保存。削除・上書き・直接編集をしません。
- 内容は架空の制作サンプル。メール送信・本番WordPress操作は行いません。
- 企業サイトへのリンクと外部配信フォントは固定保存の対象外です。
