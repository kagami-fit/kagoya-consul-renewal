# KAGOYA コーポレートサイト リニューアル案

株式会社籠や様の既存ホームページ情報をもとに再構成した、静的HTMLのコーポレートサイトです。

## ページ構成

- トップページ
- 選ばれる理由
- サービス
- 物件情報
- 会社情報
- よくある質問
- ブログ
- お問い合わせ
- プライバシーポリシー

## 確認方法

GitHub Pagesの公開URLからそのまま閲覧できます。

https://kagami-fit.github.io/kagoya-consul-renewal/

ローカルでは、このフォルダをWebサーバーの公開フォルダとして開いてください。

## 補足

静的サイトのため、入力内容の送信は株式会社 籠やの現行公式フォームへ安全に引き継ぐ導線にしています。電話リンクとブログ検索はこのサイト内で利用できます。
