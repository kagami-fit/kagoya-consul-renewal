# エフクリ・3相談窓口 ファーストビュー更新案

## 一言で言うと
添付のエフクリ画面に合わせ、3相談ページの最初の見出しを、アイボリー・グリーン・水彩イラストのファーストビューにした確認版です。元の相談ページとセミナー更新版のURLは変更せず残しています。

## 何ができるのか
- 3ページのスマホ表示を比較
- セミナーテーマ、日時、更新サムネイルを確認
- 編集前と更新後を別URLで比較
- 各ページを大きく表示
- 法律／税務／不動産のタイトルと料金・守秘の注意書きをHTMLで修正

## 構成
- index.html：3ページの比較画面
- horitsu_lp.html / zeimu_lp.html / fudosan_lp.html：各相談ページ
- *-privacy.html：各ページ専用のポリシー。共通ヘッダー・フッター・スマートフォンメニューを省き、本文と「相談窓口に戻る」リンクを表示
- style-*.css：表示用スタイル
- assets/images/：既存デザインの文字を差し替えたサムネイル3枚
- assets/images/GENERATION.md：原画像・編集指示・画像編集の記録
- seminar.json：テーマ・開催日時・サムネイルの対応
- firstview.css：新しいファーストビューと直下のナビゲーションのみのスタイル
- assets/images/efukuri-consultation-hero-v1.png：内蔵画像生成で制作した共通背景イラスト
- FIRSTVIEW-GENERATION.md：背景イラストの生成指示と保存元
- ../../scripts/build-consultation-firstview.mjs：セミナー更新版から3ページを再生成
- ../../scripts/test-consultation-firstview.mjs：タイトル・注意書き・旧版維持・本文維持・フォームの検査

## 使い方
GitHub Pagesの /review/consultation-20261010-firstview/ を開きます。フォームは無効化してあり、送信できません。公開ページなので機密情報は掲載しません。noindexは閲覧制限ではありません。

直前の版は /review/consultation-20261010-seminar/ 、さらに前の版は /review/consultation-20261010/ です。両フォルダはこの更新で変更していません。

確認コマンド：`node scripts/test-consultation-firstview.mjs`。生成コマンド：`node scripts/build-consultation-firstview.mjs`（この新規フォルダの3ページ・比較画面だけを更新）。

## 状態
2026年10月10日のファーストビュー修正依頼を反映した確認用。3ページのPC／390pxスマホ表示を確認。2026年11月6日(金) 12:05～12:55(Teams開催)のセミナー欄・サムネイル、専門家情報・本文・ポリシー・フォームは前版を維持。本番WordPressは未変更。本文画像の一部は既存公開サイトを参照しています。

指定の料金・守秘の注意書きを3窓口共通の案として配置。正式な運用前に各窓口の条件と照合してください。背景はimagegenスキルの内蔵画像生成を使用。見出しと注意事項は画像には焼き込まず、HTMLにしています。

3ページと専用ポリシーの共通ヘッダー・フッターなしの表示、各専門家のポリシー本文、相談窓口に戻るリンクは維持。

既存サムネイルは imagegen の内蔵画像編集を使用。既存の配色・構図・ロゴ・イラストを保ち、テーマと日時だけを差し替える方針です。最初のタイトル行は約2ポイント分大きい見た目に調整しています。
