# エフクリ・3相談窓口 ページ別配色のファーストビュー

## 一言で言うと
法律は紺・ブルー、税務はグリーン、不動産はターコイズに、各ページの既存色をファーストビューへ反映した別URLの確認版です。直前のグリーン共通案、セミナー更新版、元の相談ページは変更せず残しています。

## 何ができるのか
- 3ページのスマホ表示を比較
- セミナーテーマ、日時、更新サムネイルを確認
- 編集前と更新後を別URLで比較
- 各ページを大きく表示
- 法律／税務／不動産のタイトルと料金・守秘の注意書きをHTMLで修正

## 構成
- index.html：3ページの比較画面
- horitsu_lp.html / zeimu_lp.html / fudosan_lp.html：各相談ページ
- *-privacy.html：各ページ専用のポリシー。共通ヘッダー・フッター・スマートフォンメニューを省き、本文と「相談窓口に戻る」リンクを表示
- style-*.css：表示用スタイル
- assets/images/：既存デザインの文字を差し替えたサムネイル3枚
- assets/images/GENERATION.md：原画像・編集指示・画像編集の記録
- seminar.json：テーマ・開催日時・サムネイルの対応
- firstview.css：新しいファーストビューと直下のナビゲーションのみのスタイル
- assets/images/efukuri-consultation-hero-v1.png：内蔵画像生成で制作した共通背景イラスト
- FIRSTVIEW-GENERATION.md：背景イラストの生成指示と保存元
- ../../scripts/test-consultation-firstview-colors.mjs：配色と旧3版・HTML・画像・本文・フォームの維持を検査

## 使い方
GitHub Pagesの /review/consultation-20261010-firstview-colors/ を開きます。フォームは無効化してあり、送信できません。公開ページなので機密情報は掲載しません。noindexは閲覧制限ではありません。配色はこのフォルダの firstview.css だけを編集します。

直前の配色は /review/consultation-20261010-firstview/ 、さらに前は /review/consultation-20261010-seminar/ と /review/consultation-20261010/ です。これら3フォルダは変更していません。

確認コマンド：`node scripts/test-consultation-firstview-colors.mjs`。

## 状態
2026年10月10日のページ別配色依頼を反映した確認用。無料相談バッジ・見出し・ボタン・薄い背景・注意書きの枠を各ページの色に統一。3ページのHTML・背景イラスト・セミナー・本文・ポリシー・フォームは前版を維持。本番WordPressは未変更。本文画像の一部は既存公開サイトを参照しています。

指定の料金・守秘の注意書きを3窓口共通の案として配置。正式な運用前に各窓口の条件と照合してください。背景はimagegenスキルの内蔵画像生成を使用。見出しと注意事項は画像には焼き込まず、HTMLにしています。

3ページと専用ポリシーの共通ヘッダー・フッターなしの表示、各専門家のポリシー本文、相談窓口に戻るリンクは維持。

既存サムネイルは imagegen の内蔵画像編集を使用。既存の配色・構図・ロゴ・イラストを保ち、テーマと日時だけを差し替える方針です。最初のタイトル行は約2ポイント分大きい見た目に調整しています。
